Gus Uploader privacy policy

Last updated: 21 November 2026

Gus Uploader is a personal command-line tool. Its only user is the creator who owns the channels it uploads to. It is not offered to anyone else.

What it accesses

With the owner's permission, it uses the YouTube API Services to upload the owner's own videos and thumbnails, and to read the name and ID of the signed-in channel so it uploads to the right one. It requests the youtube.upload and youtube.readonly scopes only.

What it stores

The sign-in tokens and a log of uploads (video ID, title, date) are stored only on the owner's own computer. Nothing is sent to any server other than Google's. No data is sold, shared, or used for advertising, and no cookies or analytics are used.

Google and YouTube

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the computer also removes the stored data.
